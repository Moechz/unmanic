# Changelog

All notable user-visible changes to the Unmanic TOS application package.

## 0.4.1-1 — 2026-11-15

### Added
- First release. Unmanic (`josh5/unmanic:0.4.1`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8140 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/unmanicdocker/`.
